# ЛАД — дизайн-основа

> Единственный источник правды о том, как выглядит и говорит интерфейс.
> Прежде чем добавить экран, цвет, компонент или кнопку — сверься с этим файлом.
> Нужного здесь нет — сначала допиши сюда, потом в код. Токены живут
> в `web/tailwind.config.js`, компоненты — в `web/src/ui/`.

## 1. Для кого и зачем

**Кто смотрит:** завуч белорусской школы. Работает с бумагой, Excel и классным
журналом, не любит «приложения». Второй зритель — человек из Минобразования
на показе: смотрит 30 секунд и решает, серьёзно ли это.

**Главная работа экрана:** увидеть сетку, поверить ей и поправить руками,
понимая, почему что-то нельзя.

**Образ:** школьная тетрадь и учительская доска. Бумага, синие чернила,
карандаш для второстепенного, красная ручка — только для ошибок.
Не «стартап-дашборд» и не «госпортал».

## 2. Принципы

1. **Сетка — главный герой.** Смелость тратим в одном месте: на расписание
   и подсветку клеток при правке. Всё вокруг — тихое: без теней, градиентов,
   иллюстраций и анимаций на входе.
2. **Цвет — это смысл, а не украшение.** Каждый цвет отвечает ровно на один
   вопрос (§3). Если цвет ничего не сообщает — он серый.
3. **Слова завуча, а не системы.** «Урок», «окно», «клетка», «нарушение»,
   «составить». Не «solver», «job», «constraint», «слот», «штраф».
4. **Каждое «нельзя» — с причиной.** Отказ без объяснения запрещён. Если
   причина — норма, рядом стоит пункт документа.
5. **Одна главная кнопка на экран.** Остальные действия — тихие.
6. **Честные состояния.** Пустой экран говорит, что сделать дальше. Ошибка
   говорит, что случилось и как исправить, без извинений.
7. **Не добавляем, пока не попросили.** Нет иконок ради иконок, тёмной темы,
   настроек вида, анимированных счётчиков, маскотов.

## 3. Цвет

| Токен | Hex | Отвечает на вопрос | Где можно |
|---|---|---|---|
| `paper` | `#F6F8FB` | фон | фон приложения, шапки таблицы |
| `sheet` | `#FFFFFF` | где лежат данные | панели, сетка |
| `rule` | `#DDE4EF` | где граница | линии таблицы, рамки |
| `ink` | `#1C2B4F` | основной текст | текст, заголовки |
| `pencil` | `#5F6A84` | второстепенное | подписи, фамилии в клетках, пояснения |
| `pen` | `#2346B0` | что я могу нажать / что выбрано | главная кнопка, выбранный урок, активная вкладка, фокус |
| `ok` | `#2F7D55` | сюда можно | вердикт «можно», улучшения |
| `worse` | `#9A6200` | можно, но хуже | вердикт «хуже», цена хода, предупреждения по данным |
| `no` | `#C9302C` | нельзя / нарушено | вердикт «нельзя», нарушения норм, конфликты, ошибки |

У `pen`, `ok`, `worse`, `no` есть `-soft` — заливка клетки или плашки.

**Правила:**
- Имена `ok / worse / no` совпадают с `Verdict.level` в API. Один словарь от
  солвера до пикселя — не переводим.
- Красный (`no`) — **только** про нарушения и отказ. Кнопка «Удалить» — не красная,
  а тихая с подтверждением.
- Синий (`pen`) — **только** интерактив и выбор. Ссылка, выбранный урок, фокус.
- Цвет никогда не единственный носитель смысла: у вердикта всегда есть текст
  («Сюда нельзя»), у подсвеченной клетки — объяснение в панели.
- Контраст текста — не ниже 4.5:1 к фону. `pencil` на `paper` проходит.

## 4. Шрифт

**IBM Plex Sans** (переменный, оси веса и ширины) — интерфейс и текст.
Узкая ширина 85% (`font-narrow`) — только данные в тесных местах: клетки сетки,
заголовки классов. Одна семья, две ширины: узкая сама говорит «это данные
расписания».

Шрифт лежит в пакете (`@fontsource-variable/ibm-plex-sans`, файл `wdth.css`),
без Google Fonts: школьные сети бывают закрыты, а показ бывает без интернета.
⚠️ Отдельный «IBM Plex Sans Condensed» не брать — в нём нет кириллицы,
буквы молча падают на обычную ширину (найдено 14.09.2026).

Цифры везде табличные (`tnum`) — метрики и номера уроков стоят столбиком.

| Роль | Класс | Размер / строка | Вес |
|---|---|---|---|
| Заголовок экрана | `text-title` | 28 / 34 | 600 |
| Заголовок блока | `text-heading` | 17 / 24 | 600 |
| Текст | `text-body` | 15 / 22 | 400 |
| Подпись | `text-small` | 13 / 18 | 400 |
| Клетка сетки | `text-cell font-narrow` | 13 / 16 | 500 предмет, 400 фамилия |
| Метрика | `text-metric` | 22 / 26 | 600 |

**Правила:** без ВЕРХНЕГО РЕГИСТРА в подписях; без выделения одного слова
в заголовке цветом; строка текста — не длиннее ~70 знаков (`max-w-prose`).

## 5. Форма и пространство

- **Шаг — 4px.** Отступы только из шкалы Tailwind (1, 2, 3, 4, 6, 8, 10).
- **Скругления по иерархии, а не одно на всё:**
  клетка сетки — `0`, контрол (кнопка, поле, пункт выбора) — `rounded` (6px),
  панель — `rounded-lg` (10px). Больше не бывает.
- **Теней нет.** Глубина — рамкой `rule`. Единственное исключение —
  всплывающее окно поверх сетки (`shadow-pop`).
- **Иконок пока нет.** Появятся, когда слово перестанет помещаться.
- **Движение** — только в ответ на действие человека и не дольше 150 мс.
  Уважаем `prefers-reduced-motion`.

## 6. Раскладка

```
┌──────────────────────────────────────────────────────────────┐
│ ЛАД  Гимназия №…    Составление   Расписание                 │  ← шапка, 56px
├──────────────────────────────────────────────────────────────┤
│                                                ┌───────────┐ │
│   СЕТКА (скролл по двум осям,                  │ ПОЛЯ      │ │
│   шапка классов и колонка уроков закреплены)   │ что будет,│ │
│                                                │ почему    │ │
│                                                └───────────┘ │
└──────────────────────────────────────────────────────────────┘
```

- **Навигация сверху, а не слева:** 24 класса по 96px — это 2300px. Каждый
  пиксель ширины отдан сетке.
- **Поля справа (320px)** — место объяснений, как поля в тетради, где учитель
  пишет замечания. На узком экране уходят под сетку.
- **Формы и настройки** — одной колонкой шириной `max-w-3xl`, выровнены по левому краю.
- Текст выравниваем по левому краю. По центру — ничего.
- На телефоне всё работает (одна колонка), но расписание правят с ноутбука.

## 7. Компоненты (`web/src/ui/`)

Страница собирается из них. Новый компонент — только если паттерн встретился
второй раз.

| Компонент | Что это | Правило |
|---|---|---|
| `Button` | действие | `primary` — одна на экран; `quiet` — остальные. Текст — глагол: «Составить расписание», а не «Запуск» |
| `Panel` | белый лист с данными | не вкладываем панель в панель |
| `Notice` | сообщение о состоянии: `no` / `worse` / `ok` / `info` | заголовок — что случилось, текст — что делать |
| `Choice` | выбор одного из вариантов с пояснением | пункты с описанием; без описания — `Segmented` |
| `Segmented` | выбор одного из 2–4 коротких | «2 минуты / 5 / 10» |
| `Stat` | одна метрика | подпись под числом, прежнее значение зачёркнуто |
| `Reasons` | список причин/цен/выгод хода | причина + пункт нормы серым |
| `ButtonLink` | переход, который выглядит как кнопка | только в пустых состояниях и там, где переход — главное действие |
| шапка школы (`Shell.tsx`) | ЛАД, название школы, вкладки разделов | вкладки идут в порядке работы завуча; действия страницы — в заголовке страницы, не в шапке |
| `EmptyState` | пустой экран | одна фраза и одно действие |
| `Field` + `inputClass` | поле формы с подписью и пояснением | подпись над полем, пояснение под ним; ширину сужать `max-w-*`, а не `w-*` (в `inputClass` уже `w-full`) |
| `DataTable` (`ui/DataTable.tsx`) | таблица ввода: классы, кабинеты, предметы, учителя, нагрузка | поля без рамки до наведения; пояснение колонки — в `title` заголовка; сохраняет страница, не таблица |
| `Key` + `MOD` (`CommandPalette.tsx`) | клавиша в подсказке | модификатор — `MOD` (⌘ на Mac, Ctrl иначе), никогда не пишем «Cmd/Ctrl» вручную |
| `CommandPalette` | поиск ⌘K: раздел, класс, учитель | переход — только адресом (`?class=`, `?teacher=`), экран сам решает, что подсветить; строка очищается при закрытии |
| переключатель вида | кнопка с `aria-pressed`: «Трудность по дням» | включено — `border-pen bg-pen-soft text-pen`; выбор помнится в `localStorage` (`lad.*`), это вид, а не данные школы |

**Сетка расписания — прямое управление.** Одно действие — три пути: щелчок
(планшет), перетаскивание (мышь), клавиатура (стрелки, Enter, Esc, ⌘Z). Все три
зовут один и тот же ход, у всех одинаковые цвета и карточка справа. Призрак под
курсором окрашен цветом клетки под ним; своя клетка урока не красится.
Подсветка учителя — фон `pen-soft`, фамилия `text-pen`; при выбранном уроке она
уступает подсветке хода.

## 8. Слова

| Говорим | Не говорим |
|---|---|
| Составить расписание | Запустить солвер, Сгенерировать |
| Остановить и взять лучшее | Отмена, Прервать задачу |
| Сохранить версию | Submit, Применить |
| Сюда нельзя | Недопустимый слот, Ошибка валидации |
| Можно, но станет хуже | Soft-нарушение |
| Окно у учителя | Gap |
| Нарушение санитарных норм | Violation |
| Урок, клетка | Слот, ячейка |
| Подобрать замены, Лист замен | Сгенерировать замещения |
| Не заменять — урок не проводится | Отмена занятия |
| Данные школы, Внести данные | Импорт, Конфигурация |

- Действие называется одинаково на кнопке и в подтверждении:
  «Сохранить версию» → «Версия сохранена».
- Числа — цифрами, с единицами: «2 минуты», «36 окон».
- Нормы цитируем как «п. 65 ССЭТ». Непроверенные цифры норм в интерфейс
  не выводим (см. CLAUDE.md §7.5).
- Персональные данные: переключатель «Скрыть ФИО» есть на каждом экране,
  где видны учителя.

## 10. Лендинг (`landing/`) — другой режим, тот же язык

> Добавлено 19.09.2026. Лендинг — **витрина**, а не рабочий инструмент.
> Завуч сидит в приложении часами, а на лендинг человек попадает на минуту
> и должен за неё понять, зачем это. Поэтому правила §2 про тишину
> («без анимаций на входе», «движение не дольше 150 мс») на лендинг
> **не распространяются**. Всё остальное — распространяется.

**Наследуется один в один:**
- Палитра §3. Те же токены, те же смыслы. `no` — по-прежнему только про
  нарушение, `pen` — только про интерактив. Токены продублированы в
  `landing/src/app/globals.css` через `@theme` (Tailwind v4), значения
  сверяются с `web/tailwind.config.js`.
- IBM Plex Sans из пакета, `font-narrow` 85% — только на данных сетки §4.
- Табличные цифры, скругления по иерархии §5, отсутствие теней.
- Слова §8. «Составить», а не «сгенерировать».

**Отличается сознательно:**
- Размер шрифта заголовков больше, чем `text-title` (28px): на витрине
  заголовок секции работает как плакат, а не как подпись к экрану.
- Отступы между секциями крупнее шкалы §5 (`py-20`…`py-32`).
- Есть движение: сборка сетки в секции «Так это выглядит» идёт 2,4 с.
  Это единственный анимированный приём на всей странице, и он показывает
  ровно то, что делает система. `prefers-reduced-motion` отдаёт готовую
  сетку сразу.

**Жёсткие правила лендинга:**
- Только светлая тема. Образ «школьная тетрадь» в тёмной рассыпается.
- Данные в сетке — обезличенный срез настоящего `schedule.json`
  (`landing/src/data/grid.json`), а не выдуманные клетки. Пересобирается
  скриптом из `out/schedule.json`.
- Цифры только посчитанные валидатором, из `out/demo/*_report.json`.
  Демо-школы — **модели по открытым данным**, и на странице это сказано
  прямо. Формулировка «на реальных данных школы» запрещена, пока нет
  живой тарификации.
- Персональные данные §8.4 CLAUDE.md: ФИО в сетке — сгенерированные
  моделью, не настоящие учителя. При появлении реальных данных лендинг
  берёт их только через обезличивание.
