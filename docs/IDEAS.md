## Jev (OpenRouter) для разбора пожеланий учителей

*Записано 25.09.2026.* Источник: https://openrouter.ai/docs/guides/community/jev

**Что это.** Модель от TypeSafe, доступна через OpenRouter. Текст не пишет —
отвечает на узкий вопрос одним из трёх способов: выбор из списка (Choice),
да/нет (Noul), оценка на шкале (Score). Каждый ответ с вероятностью.
Быстро, платится только входящий текст.

**Где могла бы пригодиться.** Только во вводе пожеланий голосом/текстом
(его пока нет). «Иванова по вторникам не может» → Choice «тип ограничения»,
Choice «учитель» из списка школы, Choice «день». Низкая уверенность →
переспросить завуча. Плюс: выбирает только из наших списков, не выдумывает
несуществующих учителей.

**Почему не сейчас.**
- Ядро (расписание) она не заменяет — это работа CP-SAT.
- То же делает обычная LLM со строгим форматом ответа (structured output).
- ФИО учителей уходят в зарубежный сервис — лишний вопрос для Минобра/ГИАЦ.
- API в альфе (`/api/alpha/decisions`).

**Когда вернуться.** Сделали ввод пожеланий на обычной модели и упёрлись
в цену или скорость.
